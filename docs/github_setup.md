# GitHub Setup

1. Initialized a new Git repository inside my project folder:
   git init

2. Added all project files:
   git add .

3. Committed the initial version:
   git commit -m "initial commit"

4. Connected my local repo to GitHub:
   git remote add origin git@github.com:erv1029-afk/GLAB_927_1_2.git

5. Pushed the project to GitHub:
   git branch -M main
   git push -u origin main
