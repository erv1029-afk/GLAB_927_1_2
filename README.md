NLTK Stemming & Lemmatization Lab
This project demonstrates how to use Python’s NLTK library to perform key text‑processing techniques—stemming and lemmatization—in the context of managing and analyzing business email content.

The code in main.py follows the lab instructions provided in the course module and showcases how these preprocessing steps help standardize and simplify email text for categorization, filtering, and analysis.

🎯 Objectives
This lab covers:

Importing and configuring NLTK

Applying stemming with PorterStemmer

Applying lemmatization with WordNetLemmatizer

Processing sample business email text

Printing original vs. processed output for comparison

🛠 Requirements
To run this project, you need:

Python 3.x

NLTK installed

If NLTK is not installed, run:

Code
pip install nltk
▶️ How to Run
Clone or download this repository

Open a terminal in the project directory

Run:

Code
python main.py
The script will:

Download required NLTK resources

Print the NLTK version

Perform stemming on a sample email

Perform lemmatization on a second sample email
